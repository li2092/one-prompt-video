# 风格包 chat：聊天界面

来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

深靛色底上一部原创聊天界面的手机，每一场是一屏聊天，内容做成各种消息。移植自风格库的 W-聊天界面。横屏手机居中，两侧放大关键词；竖屏手机几乎占满，自上而下是聊天区、语音转文字条（字幕）、输入栏、关键词区（气泡底板）。场与场之间淡变，手机不动。

## 九种版式

- title：系统提示条（kicker）加一张群名片：强调色横幅、四宫格群头像、标题、副标题、三个圆按钮。
- statement：一条大字消息，高亮词垫强调色，落地后描边、钉图钉，随后标题栏下滑出置顶条。
- bullets：标题当群名，要点一条一条作为气泡发出来，下一条出来前冒「输入中」三点气泡。
- number：数字卡片消息（数字滚上去，单位跟后），label 在卡片里，note 是跟在后面的一条小字。
- bars：投票式图表卡片，每项一条横槽按比例填满，强调项描边、用强调色。
- steps：清单卡片，序号圆点连成一条线，每步入场时圆点填色、骨架条换成正文。
- compare：两个人各说各的：左边对方的白气泡，右边自己的气泡（accent2 色），每条带对勾，角上一颗星。
- quote：一条语音消息加转文字，播放条跟着这一场走；by 是气泡上方的发送者名，也是标题栏名字。
- end：链接卡片：预览图、标题、副标题、按钮，按钮出来后被点一下，最后手机外画一圈虚线框。

## 来自原画法库的

手机外壳、刘海、状态栏、标题栏、输入栏（style/chat 的 drawPhone）；气泡形状和阴影、输入中三点、弹出动画；图标库、头像、徽章、骨架条；语音条波形；清单卡、链接卡、点击波纹；语音转文字字幕卡和竖屏待机波形；竖屏关键词区的气泡底板；收尾包住手机的虚线框；配色（深靛底、米白屏、桃色发出气泡、紫色强调）和背景柔光、点阵。

移植时补的：群名片、大字消息、数字卡片、投票卡、对比气泡、置顶条，图钉、心形、人像、对话框、星五个图标。原头像里的字母 H 换成人像，题材文案全部去掉。

## 和原样片比少了什么

- 原样片全片是一条连续滚动的聊天记录；这里每场一屏，靠淡变衔接（接口拿不到前几场的内容）。
- 没有按旁白逐词出现的东西：两侧关键词逐词换、顶部通知、贴纸、文件卡、公式卡、书籍卡、红圈「已完成」、消息变灰框、输入栏打字再划掉。
- 字体：原样片两侧关键词用得意黑，这里用无衬线最粗一档。
- 配乐：原 A13 和弦引擎没有，换成 A7；电钢琴 lo-fi 的摇摆、底噪做不出来。

## 已知的毛病

- 横屏两侧有一侧没内容时（无标题的 bullets/bars/steps、statement 没写 highlight、quote 没写 by），画面一边空着。
- statement、number、end 没有现成的联系人名，标题栏名字画成一条骨架条。
- 标题栏名字长时折两行，横屏字约 26px，偏小；两侧关键词里有大字兜底。
- 字号倍数每场自动选（0.64 到 1.3 倍），不同场的气泡字大小不一样。
- bars 每项标签只给一行，长标签会缩小。置顶条的字超长时截断加省略号（重复出现的字，没走 E.fit）。
- 竖屏关键词区和输入栏落在底部平台界面区，可能被平台标题盖住；那里只放重复的字。
- statement 原先在气泡外手画一圈（原画法库的 loop），气泡高时圈会压到字，改成描边。
- 配乐没有人耳听过。
