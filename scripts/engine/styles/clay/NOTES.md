# clay：黏土卡通风格包
来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

`"theme": "clay"` 即用。舞台是一面抹过的马卡龙色墙和一张焦糖色黏土桌，每场换一种墙色（片头片尾用 `bg`）。画面上的东西都是预渲染的黏土贴图：手捏轮廓、体积渐变、内阴影和高光、指纹和捏痕、颗粒、接触阴影，待机时按每秒 12 次轻微颤动。主角是原风格的圆头小机器人（会眨眼、呼吸，有开心、发愁、张嘴三种表情）。字有两种：黏土大字（中文加一圈深色黏土描边），和刻进黏土牌里的字。

## 九种版式
- `title`：kicker 是浅蓝小牌；标题一个字一块黏土，依次掉下来压扁；副标题刻在奶油色牌上；机器人在桌上挥手，桌上有小球、小方块。
- `statement`：整句刻在一块架在两条黏土腿上的大板上，高亮词压上一条强调色黏土；机器人指着高亮词。竖屏板子在上，机器人在下面仰头指。
- `bullets`：一条一块刻字牌，左端压一颗带编号的彩色黏土球，依次短距离掉下；机器人指着最新的一条（横屏站右侧，竖屏站在列表下面）。
- `number`：每个字符是一块鼓起来的黏土，从 0 滚到目标值，滚完挨个压一下；单位是蓝色黏土小字，label 刻字牌，note 是浅色纸条；机器人仰头看，滚完跳起来欢呼。
- `bars`：黏土柱从桌面鼓起来，强调的那根用强调色；柱脚立着刻名字的小牌。横屏数字是柱顶的黏土小字，机器人在右边欢呼；竖屏数字刻在柱子里，机器人跳到强调的那根柱顶上。
- `steps`：一步一个黏土圆台，越往后越高，机器人从一个跳到下一个，路上留一串小黏土点。横屏字刻在圆台正面；竖屏圆台排在桌上，字牌在墙上排成一列，编号和圆台对应。
- `compare`：两只机器人各举一块牌子：左边奶油色、机器人发愁挠头冒汗；右边强调色、机器人开心地蹦，牌角画勾。横屏牌子挂在杆上、机器人在外侧握杆；竖屏和方形是并排两块，机器人在下面举着。
- `quote`：机器人张嘴说话，话在黏土气泡里，尾巴指向它；角上一对强调色黏土引号；出处刻在桌上立着的浅蓝小牌上。
- `end`：浅蓝黏土大字掉下来，副标题刻字牌，按钮是一块强调色黏土，每 1.1 秒压一下；彩色黏土小球落下，机器人挥手。
- 字幕：每段一块刻字的奶油色黏土牌，立在桌子前立面上，换段时压一下。最上层是一圈很淡的暖色暗角。转场是自己写的函数：下一场在一团手捏的不规则圆里从中间压开，边上带投影和亮脊（0.5 秒）。
- 声音：bright、C–Am–F–G、pluck、有鼓、112 拍。音效：入场 pop，换场 whoosh，number 和 statement 落地 thud；另在大字落地、数字滚完、最后一级台阶时加 chime，强调的柱子长好时加 thud。

## 颜色
`bg` 墙，`fg` 字，`muted` 纸条上的小字，`accent` 大字、高亮、强调柱、按钮、天线球，`accent2` 机器人、单位，`card` 字牌和大板，`line` 桌子，`onAccent` 强调色上的字（默认是深色，因为默认强调色是浅珊瑚色；换成深色强调色时要把它一起换成浅色）。场标题的奶黄牌、编号球的几种马卡龙色、腮红、绿勾、汗珠是固定的装饰色，不随 `colors` 变。

## 和原样片比少了什么
1. 按旁白逐词触发的动作全没有：念到哪个词就弹出哪块牌子、镜头推近和抖动、机器人走位（原来的 4 帧走路循环和侧身走已删）、挠头时机、彩屑爆开。这里只按 s.p(i)、s.cue(i)、s.t 动。
2. 原样片的题材道具（圆环托盘、扳手、停止牌、放大镜、书、对话窗等）没有搬；新做的是圆台、旗杆、桌上小摆件、黏土引号。
3. 配乐用引擎现成的参数，没有原来的尤克里里扫弦、马林巴点缀和沙锤。
4. 字幕按标点切段，没有按逐字时间戳拆句。
5. 转场里上一场改成微微鼓起：原样片是往里缩，在这个引擎里缩了会露出画布边上的残影。

## 已知的毛病
- 贴图是预渲染的：柱子长高、牌子弹出时，高光和指纹跟着一起拉伸。大板、气泡上的指纹圈比较大，近看像污渍。
- 竖屏 steps 中间一段偏空，机器人在空中跳；五步时墙上的字牌偏小。
- compare 每边四条时，横屏条目字约 38px；方形画幅的 compare 板子窄，条目字更小（字号随行高定，报告里不会提示）。
- bars 竖屏六根柱子、标签长时，标签会折两行并缩到约 25px（报告里有「字偏多」）。
- 列表行掉下来的约 0.2 秒里会压到上一行一点。
- 竖屏片头字号大，标题超过 12 个字时报告会提示「字偏多」（缩字号，不出画）。
- 方形画幅只看过一张总览图；`colors` 只试过换浅色墙和蓝色强调色。
- 换过画法的：compare 横屏原来让机器人站在牌子下面举牌，牌子被压得太矮、条目字只有约 29px，改成牌子挂杆、机器人站外侧。
