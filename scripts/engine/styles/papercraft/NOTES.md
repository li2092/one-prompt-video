# papercraft 纸艺定格 · 风格包说明
来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

`"theme": "papercraft"` 即用。每一场是一个纸艺景箱：天空底卡、吊线纸云、纸太阳（片尾是纸月亮和吊线星星）、远中近三层剪纸山丘，近景山丘压在内容前面；内容全是带投影、剪口有浅边的彩色卡纸，由一个纸片小人来演。全片每秒换 8 张：所有运动按全片时钟取整，一格一格走；每块纸每格轻抖一下，剪纸轮廓每两格换一次扰动；纸纹和暗角只算一次压在最上层，不跟着抖，另加每格一点明暗闪烁。转场是一张带毛边的新卡纸分四格从右边推进来。字幕是撕边纸条加一小块胶带。

## 九种版式

| 版式 | 画法 |
|---|---|
| title | 一块大纸牌从景里立起来（横屏立在两根木桩上、按格拉高，竖屏两根线吊下来），标题是一张张字块；kicker 压在牌子上沿，副标题是压在下沿的牛皮纸条；小人站在一旁，标题到齐后挥手 |
| statement | 一张大纸用两根线吊下来，高亮词贴上强调色纸条；小人在旁边仰头看 |
| bullets | 一根纸横杆下挂一串纸牌，一张吊着下一张，每张晃着进来；横屏小人在右边指着 |
| number | 剪出来的纸数字（纸厚、浅色剪口）立在一摞牛皮纸板搭的台子上，从 0 滚到目标值；label、note 是贴在台子正面的纸签 |
| bars | 每根柱子是一摞纸块，一块一块落上去；数值签贴在顶块正面，标签是插在地上的纸签；最高（或 highlight）那摞是强调色，摞好后小人跳上去 |
| steps | 横屏一排越来越高的纸柱，竖屏左右交错、从下往上的纸搁板；小人一块一块跳过去，最后一块上欢呼 |
| compare | 左右（竖屏上下）两个纸舞台：波浪边帷幔上是标题，侧幕、台板，台上一条条纸签；右边强调色、条目前贴纸条勾；每个台上一个小人 |
| quote | 小人站在左下，说出一只大纸气泡（尾巴指向它的头），左上角压一枚剪出来的大引号，出处是牛皮纸签 |
| end | 夜景。标题字块一块块吊在线上轻轻晃，副标题纸签，按钮是有厚度的纸按钮、会被按一下；小人挥手 |

## 来自原画法库

`lib/paper.mjs`：剪纸轮廓和 boil、投影、纸卡、字块、纸条勾、细绳、铆钉、定格抖动。`lib/stage.mjs`：七套景箱配色、山丘和纸云贴图、太阳月亮、纸风车 / 吊挂齿轮 / 三角旗 / 吊线星星、按景深推近。`lib/doll.mjs`：六角对折头、打孔纸框身、铆钉手脚、天线纸风车。改动：尺寸全部乘 `E.u`；字体走 `E.font` / `E.fit`；定格从 12 张改成每秒 8 张，且按全片时钟取整；小人纸框颜色跟 `accent2`；用户换了 `bg` 时布景往新色调靠。

## 和原样片比少了什么

- 没有按旁白逐词触发的事件（勾叉来回翻、盖章、公式逐项点亮、纸框装上拆下），动画只按 s.cue、s.t。小人不再表示任何概念，只是吉祥物。
- 没有每场单独写的镜头推拉横摇，只有整场一格一格推近 3.5%；没有傍晚变色的天空、路牌、书堆、终点旗。
- 没有音乐盒音色：选了 bright + pluck、不加鼓、96 拍；音效 pop / whoosh / chime，另加三个（台阶走到头 chime、小人跳上最高那摞 tick、片尾按钮 thud）。
- 字幕不给关键词换色；没有横屏左上角的书签。

## 已知的毛病

- 本机没有手写体，`hand` 退回无衬线，正文和字幕都是黑体。
- 竖屏 number 的台子偏高，画面上三分之一只有天空（改了两轮：台子换成纸板摞、数字放大，仍偏空）。
- 1:1 用横屏的摆法：compare 的条目偏挤，title 小人的手会碰到牌子。
- 值为 0 的柱子没有纸块，数值签落在地上；highlight 指定的那根很矮时，数值签放在柱顶上方，跳上去的小人会压住它。
- 画面按每秒 8 格取整，元素比入场音效最多晚 1/8 秒。抖动幅度没在手机上看过。
- 阴影多，出帧约每秒 15 帧（1080p），比内置主题慢。
