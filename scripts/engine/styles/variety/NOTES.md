# variety：综艺花字风格包
来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

综艺节目式的热闹画面。每场换一套高饱和渐变底（五套轮换，全部由 `colors` 的八个颜色算出），上面慢转放射线、斜向漂移波点。字是多层描边花字：深色硬投影、白宽边、彩色描边、上浅下深的渐变字芯，逐字弹出、砸下或掉落。配贴纸、「划重点」贴条、爆炸框、彩纸、冲击环、边缘速度线，和一个原创的软糖吉祥物（天线星星、大眼睛，跟 128 拍一颠）。顶部一条单行弹幕，只飘这一场 `s.scene` 里已经入场的字。

## 九种版式
- title：放射线亮起，标题逐字砸下，落地时冲击环、彩纸、速度线；kicker 是深色胶囊，副标题是白贴纸；吉祥物在右下欢呼（竖屏在副标题下面）。
- statement：白芯深边花字逐字弹出，高亮词换成黄橙渐变、紫边、白宽边的花字并上下跳；「划重点」贴条拍在字块左上角；吉祥物从震惊变得意。
- bullets：每条一张彩色花字贴条，从左右轮流甩进来，左端压编号徽章；要点不多时吉祥物伸手指着最新一条，五条时不画吉祥物。
- number：放射线上两层反向旋转的爆炸框，数字砸进来再滚到目标值，滚完炸彩纸；label 是白贴纸，note 是深色胶囊；吉祥物看呆。
- bars：彩色贴纸柱弹着长高，高亮的那根是黄色、数值用花字、头上闪星星；吉祥物站在离它近的一侧伸手指着。竖屏改横条。
- steps：背面朝上、带编号的翻牌任务卡随标题弹出，到第几步翻开第几张，翻开的卡之间亮起箭头。竖屏和方形排成一列。
- compare：左右两块牌子从两边甩进来，撞上时画面一抖，中间砸下「VS」爆炸框；右边是黄牌、星星标记。竖屏上下摆。
- quote：吉祥物举着话筒，引语装在大对话气泡里，左上角一个花字引号；出处是紫色胶囊。
- end：收束的话是掉下来的花字，副标题是深色贴纸，cta 是随拍子跳的粉色大按钮；吉祥物站在跑马灯圆台上欢呼，彩纸一阵阵炸开。
- 字幕：白字深色粗描边加硬投影，换段时弹一下。转场：0.5 秒十二角星旋转爆开，星边三层描边。
- 配乐：drive，C–G–Am–F，pluck，有鼓，128 拍/分。音效：入场 pop，换场 whoosh；片头落地、number、statement、VS 一记 thud；数字滚完、高亮柱长好、片尾各一声 chime。

## 来自原画法库的部分
`lib/fx.mjs`：花字 `hz`、入场 `put`、贴纸、胶囊、贴条、放射线、速度线、星星、爆炸框、彩纸、冲击环、粗线、箭头、徽章、气泡、圆台。`lib/mascot.mjs`：吉祥物，新加 cheer、point、mic 三个动作，去掉肚子上的字。`lib/stage.mjs`：底色、波点、弹幕条、字幕、星形转场。颜色改从 `this.c` 取，字体走引擎的 sans，动画改由 `s.p(i)`、`s.cue(i)`、`s.t` 驱动。花字描边按原尺寸单帧定：白边 0.22 倍字号、彩边 0.1 倍，statement 正文深色边 0.13 倍，笔画密的字（鑿、麤、龘）也读得出。

## 和原样片比少了什么
1. 原样片的动作挂在旁白逐字时刻上（念到哪个词砸哪个词）；这里只按元素入场时刻。
2. 和题材绑定的道具（计分板、模型芯片、外框、文档、图标）没搬；镜头推近、全屏闪白、全屏爆点花字也没做，一屏只留一个主角。
3. 原样片用一款圆润的展示字体做花字；这里不写死字体，本机落到黑体且只有常规字重，花字比原来细。
4. 弹幕原来按旁白念完的词排；这里按元素入场排，每条最多飘两次，换场时弹幕条清空。

## 已知的毛病
- 方形画幅里 title、statement、number 的吉祥物和字相交，会先缩到 0.75 倍，再不行就不画。
- 逐字砸下的头 0.1 秒字放大到 1.7 倍，相邻的字有短暂重叠。
- 横屏 bullets 的贴条从右边甩进来时会从吉祥物身前掠过约 0.2 秒。
- bars 的吉祥物离高亮那根远时（柱子多、高亮在中间），手指的方向只是大致对准。
- 只验证过一组深色换色；`bg` 换成浅色时，白芯花字在亮底上会偏淡。
