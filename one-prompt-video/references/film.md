# 自由画面的短片

填表出的是版式片。用户要的是有场景、有角色、有故事的短片，或者一整支都是自己设计的画面（剪纸拼贴、插画场景、像素动画、图解、特效演出），走这里：你写一个 `film.mjs`，里面的 `draw(ctx, t, E)` 画出第 t 秒的画面，脚本负责排镜头、出静帧和总览图、配乐、编码、自检。只要 Node.js 和 ffmpeg，不要浏览器。

先判断该不该走这里：

- 这条路线要自己写几百到上千行画面代码，并且对着出来的图一轮一轮改。看不了图的、写不了这么多代码的，如实告诉用户，改走填表。
- 用户只是想要一种好看的版式片，先看内置主题和风格包够不够（`SKILL.md` 的主题表）。
- 3D 场景、全屏着色器的自然景见 `pipelines.md`；要写实渲染见 `external-tools.md`。

## 流程

1. 把一句话补成一个方案，写在 `片名/方案.md`：故事（三句话以内）、角色、场景、画法（媒材）、配色（五六种颜色以内）、镜头表、声音。用户没说的自己定，最后告诉用户你定了什么。
2. 先画全片最重要的那一个画面，出静帧看，改到成立。画面成立的标准见下面「画面」一节。
3. 找出最没把握的一处（一个角色动起来、一个转场、一种质感），单独做两三秒，出小样看。做不出来就改方案，不带着它往下做。
4. 按镜头表一个镜头一个镜头写，每写完一个出总览图看。
5. 写配乐和音效，出成片，读自检报告，再看一遍每秒一格的连续总览图。
6. 告诉用户：成片在哪；你替他定了什么；哪些内容是你补的；画面、动作、配乐好不好你判断不了，请他看一遍、听一遍。

```bash
node "SKILL/scripts/film.mjs" 片名/film.mjs --still 2,7.5     # 出静帧
node "SKILL/scripts/film.mjs" 片名/film.mjs --sheet           # 每个镜头的开头、中间、结尾各一格
node "SKILL/scripts/film.mjs" 片名/film.mjs --strip           # 每秒一格
node "SKILL/scripts/film.mjs" 片名/film.mjs --shot 3          # 只出第 3 个镜头的小样（半尺寸、无声）
node "SKILL/scripts/film.mjs" 片名/film.mjs                   # 出成片，报告存在 片名/out/report.txt
```

环境和主生产线一样：先在工作目录跑一次 `node "SKILL/scripts/setup.mjs"`。

## film.mjs 的写法

```js
export const meta = {
  title: '片名',                 // 也用作输出文件名
  aspect: '16:9',                // 16:9 | 9:16 | 1:1
  fps: 30, bpm: 90,              // 30 帧每秒时用 72、90、100、120，一拍才是整数帧
  shots: [                       // 镜头表：beats 是几拍，也可以写 seconds
    { id: '书桌', beats: 12 },
    { id: '街道', beats: 16 },
  ],
}

export function setup(E) { return { stars: … } }     // 可选：预先算好的东西，返回值在 E.state

export function draw(ctx, t, E) {                    // 画出第 t 秒
  const s = E.shot(t)                                // s.id 镜头名，s.lt 镜头内秒数，s.p 镜头内进度 0–1
  if (s.id === '书桌') drawDesk(ctx, s, E)
  else drawStreet(ctx, s, E)
}

export function score(M, E) {                        // 可选：配乐。M 是合成器，E.beat 是一拍的秒数
  M.pad(0, E.chord('Am9', 3), E.bar * 4, 0.4)
  for (let b = 0; b < 16; b++) M.pluck(b * E.beat, E.chord('Am9', 4)[b % 4], 1, 0.6)
}

export const sounds = [                              // 可选：音效表，at 是全片的秒数
  { at: 4.0, kind: 'whoosh', gain: 0.3 },            // tick click type pop thud chime whoosh swell glitch
]
```

- 没有 `score` 和 `sounds` 的片子没有声音，脚本会提醒，要告诉用户。也可以用自己的音频文件：`meta.music: 'music.wav'`；人声：`meta.voice: [{ file: 'vo/01.mp3', at: 1.0 }]`，人声响起时配乐自动压低。真实乐器的配乐和自然的人声见 `external-tools.md`。
- 合成器 `M` 的乐器：`piano epiano pluck marimba bell pad bass kick hat shaker rim clap air`，写法见 `SKILL/scripts/engine/synth.mjs`。和弦 `E.chord('Fmaj7', 3)` 返回音高数组。
- 片头从黑场淡入 0.35 秒、片尾淡到黑 0.8 秒；不要就写 `meta.fadeIn: 0`、`meta.fadeOut: 0`。

工具箱 `E`：

| 名字 | 是什么 |
|---|---|
| `E.W` `E.H` `E.u` `E.portrait` | 画面宽高；`u` 是缩放单位，尺寸写成 `n * E.u`；是不是竖屏 |
| `E.shot(t)` | 第 t 秒在哪个镜头：`{ id, i, t0, dur, lt, p, first, last }` |
| `E.at('街道', 4)` | 「街道」这个镜头开始后第 4 拍是全片的第几秒。音效、配乐的时刻用它算，不写死秒数 |
| `E.total` `E.beat` `E.bar` `E.fps` | 全片秒数、一拍和一小节的秒数 |
| `E.key([[时刻, 值, 缓动], …], t)` | 关键帧表取值；值可以是数或数组 |
| `E.rng(种子)` `E.hash(a, b)` `E.noise(x, y, 种子)` `E.fbm(x, y, 层数, 种子)` | 种子随机、哈希、平滑噪声和它的多层叠加 |
| `E.ease.*` `E.prog(t, t0, 时长, 缓动)` `E.clamp` `E.lerp` | 缓动和进度 |
| `E.rgba` `E.mix` `E.roundRect` | 颜色和圆角矩形 |
| `E.font(类别, 字重, 字号)` | 类别是 `sans`、`serif`、`hand`、`mono`。不要写死字体名 |
| `E.fitText` `E.wrapText` `E.drawLines` | 排字 |
| `E.layer(w, h)` | 一张离屏画布：纹理、图层、转场时把上一个镜头先画在上面 |
| `E.once(名字, () => …)` | 只算一次的东西（纸纹、星空、静止的背景）：第一次用时算，之后直接取 |
| `E.kit.*` | 现成的画法库（有的话）。它们是起点，不合适就自己写 |

## 都要守的

1. 画面只由时刻决定。`draw` 不用 `Math.random()`、`Date`，不依赖上一帧；随机数从固定种子算。脚本会把同一时刻画两次比对，不一样就报 `[问题]`。
2. 每个镜头里至少有一样东西在动，不能只有镜头在慢慢推。脚本会比对每个镜头的开头和结尾，几乎一样就提醒。
3. 切到新镜头的那一帧，要紧的东西已经在画面里了。
4. 转场在画面里要有来由：上一个镜头的一样东西变成下一个镜头的一样东西（形状、颜色、运动方向接得上），或者被画面里的物件遮过去。做法是把上一个镜头画到一张 `E.layer()` 上，再按进度处理它。
5. 手绘感的抖动每秒换 7 到 8 次（`Math.floor(t * 8)` 当种子），每帧都换会读成噪点。背景的纹理只画一次，不跟着抖。
6. 表演写成关键帧表。起跳前先压扁，空中拉长，落地再压扁；表情变化时身体先停一下；一次只演一件事，留够看懂的时间。
7. 画面里的字越少越好，写在画面里的物件上；用户要的信息量大时改走填表。

## 画面

一张画面成立，至少要有这几样：

- 层次：前景、中景、远景至少三层，远处的颜色更淡、对比更低。
- 光：一个明确的主光源（灯、窗、月亮、屏幕），它照到的地方亮、带光晕，背光的一侧暗，物体有投影和贴地的阴影。
- 媒材：选一种，全片统一，按它的物理过程画。剪纸是一层一层的色块加投影和纸纹；印刷是网点和错版；水彩是晕开的边和纸的颗粒；像素是整格、不抗锯齿。
- 颜色：一个主色调加一两种点睛的颜色，同屏不超过五六种。
- 焦点：一屏一个主角，别的都让它。角色占画面高度三分之一左右才读得出动作。
- 没有大块空白的纯色底，也没有标题栏、卡片、项目符号这类版式元素。

每一轮都出图自己看，按上面几条挑毛病。出全片之前，把每个镜头的第一帧和最后一帧并排看一遍。
