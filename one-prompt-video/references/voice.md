# 加人声

默认成片没有人声：字幕加程序合成的配乐。这样三个系统都不用装语音软件，也不用联网。要人声有两种办法，都由用户提供声音，本技能不自带配音服务。

## 办法一：放录音文件

在 `video.json` 旁边建一个 `voice/` 目录，按场号放文件：

```text
片名/
  video.json
  voice/
    01.wav     第 1 场的人声
    03.mp3     第 3 场的人声（不是每场都要有）
```

- 文件名是两位场号，格式可以是 wav、mp3、m4a、aac、flac、ogg、aiff。
- 有人声的场，时长按录音的长度定（录音长度加 0.7 秒）；人声响起时配乐自动压低。
- 录的内容照这一场的 `say` 念。

## 办法二：配一条自己的配音命令

用户机器上有能从命令行出声的工具时（系统自带的、自己装的、自己有密钥的服务），在 `video.json` 最外层写：

```json
"tts": { "command": ["工具名", "参数", "{text}", "参数", "{out}"], "ext": "wav" }
```

- 脚本对每个有 `say` 的场跑一次这条命令：`{text}` 换成这一场的 `say`，`{out}` 换成输出文件路径（`voice/场号.ext`）。
- 命令写成数组，一个参数一项，不经过 shell。
- 已经生成过、文字没变的场会跳过。

各系统自带的工具举例（音质有限，适合打样）：

```json
"tts": { "command": ["say", "-v", "Tingting", "-o", "{out}", "--data-format=LEI16@48000", "{text}"], "ext": "wav" }
```

上面是 macOS 的 `say`。苹果的许可只允许个人非商业使用这些声音，对外发布的片子换别的。Windows 可以用 PowerShell 调系统语音，Linux 可以用 `espeak-ng`，写法类似。

## 提醒用户的事

- 配音是 AI 合成的，发布时按平台要求声明。
- 用第三方配音服务前看它的条款：能不能商用、要不要署名。
- 念错的字机器查不出来，成片要人听一遍。
