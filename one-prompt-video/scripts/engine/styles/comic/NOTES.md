# comic：漫画分镜风格包

来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

一场是一页漫画：米白纸面上排黑色粗框格子（格边 7px，格缝斜切），格子带硬投影。还没轮到的格子先画成铅笔虚线空格，轮到时砸进来（0.24 秒放大回弹）。画面只用墨、白、网点灰和一种强调色（`accent`）。主角是原样片的刺头小人，九种版式里都有它。

## 九种版式

- `title`：扉页大格，四周是渐变网点。标题用冲击字（黑外描边加白内描边）砸下来，落地后集中线指向它。kicker 放黑旁白框，副标题放白旁白框，角上的小人欢呼，配一个拟声字。
- `statement`：分成两格。大格里，句子落地前是下坠的速度线，落地后换成集中线，整页一抖，高亮词用强调色。旁边一格是小人吓一跳。
- `bullets`：页首横格写场标题，下面一条一格，依次砸入。横屏 3 格以内排一排，4 格排两行两列，5 格上三下二；竖屏排一列，格缝倾斜。最新一格带集中线，格子背景轮换三种网点，每格里的小人换一种动作。同一页的字号统一。
- `number`：带集中线的大特写。数字压在爆炸框上滚上去。角上斜压一小格，小人看呆了。
- `bars`：图表画在格子里。柱子是白底网点、黑描边带硬投影，高亮的那根用强调色，拟声字砸在它上面。竖屏改成横条。
- `steps`：沿阅读方向排格子，同一个小人一格一格往前跑，最后一格欢呼，格缝里的三角箭头指向下一格。页面宽高比小于 1.6（竖屏、方形）时改成一列，从上往下读。
- `compare`：左右两格，中间斜着劈开，格缝上有一个 VS 爆炸框。右格的网点用强调色，两边小人对峙。竖屏改成上下两格。
- `quote`：对话气泡。小人开口说出这句话，出处写在旁边的旁白框里。
- `end`：一张黑底大格斜压在一页空格上，白色集中线配白字红边的大标题，cta 放红旁白框，小人挥手，最后从右边推进一个「TO BE CONTINUED」箭头。
- 字幕：用原样片的旁白条，黑底白字，内嵌一圈白细线，带硬投影。
- 配乐：drive，Em-Em-C-D，pluck，有鼓，126 拍/分。音效：元素入场 pop，换场 whoosh（原样片翻页用的声音），number 和 statement 落地 thud。

## 来自原画法库的部分

`lib/comic.mjs`：分格多边形、格子砸入和铅笔空格、整页抖动、均匀和渐变网点、集中线（每秒重抖 12 次）、速度线、入场（pop / slam / drop）、冲击字、拟声字、旁白框、对话气泡、爆炸框。`lib/agent.mjs`：小人整套（眼睛、嘴、手势、腿、汗滴、惊吓线、问号、感叹号、闪光）。颜色改从 `this.c` 取，字体改走引擎的 sans、hand 两类，入场改成按 `s.p(i)` 驱动。新写的部分：横排和竖排的分格函数（`cols`、`rows`，格缝斜度交替）、页面区、九种版式的构图。

## 和原样片比少了什么

1. 转场：原样片轮换右翻页、下翻页、分格框砸入和黑页直切。引擎只提供 cut、fade、slide 三种，这里用 cut，换场配 whoosh。
2. 镜头读格：原样片会推近正在念的那一格，其余格子罩一层纸色。这里没做，镜头始终看整页。
3. 铅笔稿：原样片会先把没念到的格子画成灰色草稿。这里只画虚线空格，不提前露出字。
4. 毛笔拟声字：原样片用马善政楷书。本机没有任何手写体，`E.fonts.hand` 退回黑体；装了楷体会自动用上。
5. 最上层：原风格本来就没有最上层的元素，所以没写 `overlay`。
6. 原样片里与题材绑定的图标（芯片、文档、扳手等）没有搬，版式里的内容只来自 `s.scene`。

## 已知的毛病

- 整页抖动和拟声字只在元素落地的约 0.16 秒内发生。原因：接口只给 0 到 1 的入场进度，进度到 1 之后，无法知道元素已经落地多久。
- number 的滚动按 `s.t` 从 0.3 秒起算，和数字的入场时刻对得不严。
- 竖屏 5 条要点时每格只有约 216px 高，格里的小人很小。
- 「TO BE CONTINUED」、「VS」是固定的英文装饰词，中文片里也是英文。拟声字会自动切换：画面上有汉字时用中文（锵、咚、轰、砰），否则用英文（BAM 等）。
- 画法默认浅色纸、深色墨：只验证过换强调色和换浅色纸，把 `bg` 换成深色的效果没测过。
- 1:1 画幅只看过一张总览图：steps 自动改成一列，其他版式沿用横屏的摆法。
