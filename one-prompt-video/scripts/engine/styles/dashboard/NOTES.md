# dashboard：数据仪表盘风格包
来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

暗色数据大屏。深蓝黑底铺 32 格点阵，一道淡扫描带缓慢下行；内容全装在面板里，面板是整圈细边加四角括号（括号点亮时多一道半透明粗线当光晕）。每一场先以灰色骨架出现（灰框、骨架条、虚线占位），再按 `s.p(i)` 一块一块点亮。强调色（`accent`）只标当前点亮的那一块和 highlight，点亮过的部分退回由 `muted` 和 `fg` 调出的 calm 色。页眉在最上层：LIVE、跳动的小柱、骨架条、ONLINE 和不带数字的场次格。字幕是带四角括号的深色条。转场是一条强调色扫描线自上而下刷新整屏（0.5 秒）。所有颜色从 `this.c` 推出，换 `colors` 整套跟着变。

## 九种版式
- `title`：大屏开机。四块装饰面板的骨架依次亮出、点亮，中间主面板被一道扫描光扫过后出标题；kicker 是标题上方的胶囊，标题下一道强调色细线，副标题在下面。
- `statement`：结论面板。那句话逐行写出，光标走过，没写到的部分是骨架条；高亮词写完后变强调色，套上四角括号的选框。旁边的装饰面板随后点亮。
- `bullets`：事件流面板。场标题在标题栏，每一条是一行日志，从右边滑进来、闪一下，带编号、状态点和一个画出来的勾；最新那条是强调色，状态点在呼吸。空位是骨架行。
- `number`：大 KPI 卡。数字从 0 滚上去，一圈 270° 仪表弧同时扫满（不表示比例），落定时一道冲击环，弧端点在呼吸；label、note 在仪表下面。两侧（竖屏是下方）是装饰面板。
- `bars`：图表面板。开场一道扫描光扫过空图表；横屏竖柱、竖屏横条，柱子在灰色轨道里长出来，刚长出的那根闪强调色，highlight 那根一直是强调色并带光晕，柱顶数据点在呼吸。网格线没有刻度值。
- `steps`：流水线面板。节点依次点亮，点亮的轨道上有光点流动；当前节点是强调色并一圈圈外扩，走过的退回 calm；每个节点挂一张小面板，没轮到的是虚线占位。竖屏轨道竖在左边。
- `compare`：标题条一块，下面左右两张面板，左边点亮后退回 calm，右边是强调色；条目一行行落进来。两张面板之间一条连线，光点来回走，中间一个双向箭头圆标。只有竖屏上下叠，方屏仍左右排。
- `quote`：批注面板。旁边一块装饰折线，引语点亮时折线上一个点被圈出来，引线连到批注面板；面板里一个大引号、逐行写出的引语，出处是右下角的胶囊。
- `end`：主面板被扫描光扫过，出收束的话和副标题，cta 是强调色的按钮；下面一排装饰面板一块接一块点亮。
- 装饰面板只有不带标注的线条和形状：漂移的折线、起伏的小柱、转动的环、闪烁的点阵、滚动日志带。没有数字、刻度值、单位、日期、指标名。装饰短词只有 LIVE、ONLINE。
- 配乐 drive，Dm–B♭–F–C，pluck，有鼓，116 拍/分。音效：点亮 pop、换场 whoosh、计数开始 tick；片头标题、片尾标题、高亮柱各一声 chime，KPI 数字落定一声 thud。

## 来自原画法库的部分
`lib/dash.mjs`：面板、四角括号、胶囊、折线、圆点、圆弧、冲击环、勾、扫描光，调色改从 `this.c` 推。`lib/deco.mjs`：装饰面板（原样片 jobs 场的小图和竖屏日志带的画法）。`lib/frame.mjs`：底、扫描带、竖屏日志带、页眉、字幕、扫描线转场。原代码里的 `shadowBlur` 全部换成半透明粗描边和径向渐变；静止的底只画一次。整支 44.6 秒的横屏片出帧 13.4 秒。

## 和原样片比少了什么
1. 点亮不再挂在旁白的词上（原样片用逐词时间戳），只按 `s.p(i)`、`s.cue(i)`、`s.t`。
2. 三种发光色的固定含义（正常、harness、警示）和玫红、绿两种状态色都去掉了，只剩强调色和 calm。
3. 原样片的数据图（成功率曲线、跳动的 KPI、指纹柱、候选柱、覆盖计数、拓扑环）都带编出来的数，没搬；换成不带数的装饰面板。「示意」胶囊、出处条、页眉的书名和计时也去掉了。
4. 字幕里给关键词上色、按逐字时间戳拆句没做，分段用引擎默认的算法。
5. 配乐用引擎现成的 drive 加 pluck，不是原样片的十六分合成器琶音和逐场编排。

## 已知的毛病
- 装饰面板不带信息。内容抽象时观众可能去猜那些折线和小柱是什么意思，这是这个风格的固有短板。
- statement、quote 的逐行写出用的是 `s.t - s.cue(0)` 自己的节奏（每行约 0.3 秒），比入场音效长；四五行的长句要一秒多才写完。
- 方屏用竖屏的上下叠摆法（compare 除外），装饰面板偏扁。
- 竖屏底部的滚动日志带从面板区下面一直铺到画面底边，字幕条压在它上面。
- 只测过深色 `bg`；浅色 `bg` 下骨架条、calm 色和点阵的对比没测过。
- 场次格最多占页眉宽度的四成，二十场时每格很细。
