# arcade 街机关卡 · 风格包说明

来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

8-bit 平台游戏风。`"theme": "arcade"` 即用。所有图形落在像素网格上（短边 1080 时一格 6px），贴图最近邻放大，没有圆滑边。每种版式是一个游戏画面，字幕是 RPG 对话框，最上层是扫描线和 HUD（1P、三颗心、SCORE、金币、关卡号）。

## 九种版式

| 版式 | 画法 |
|---|---|
| title | 白天外景卷轴（远云、云、山、灌木、砖地）。红色招牌上是中文像素大标题，kicker 是压在招牌上沿的小牌，下面副标题和闪烁的 PUSH START；主角在地上跑、吃迎面来的金币 |
| statement | 黄昏城堡关。RPG 消息框里逐字打出中文像素字，高亮词金币黄；主角站在框下（横屏左下、竖屏正下），头上冒「!」 |
| bullets | 星空装备栏。每条要点是一格装备：没入场是虚线空格，入场时图标落进格子，同一件装备落到右边（竖屏下边）主角身上；▶ 光标停在最新一条 |
| number | 奖励关。同心方环调色板循环；记分牌里点阵数字从 0 跳到目标值，中文单位是像素字；跳完后两侧金币雨、烟花 |
| bars | 横屏：一排砖块塔一层层长高，最高（或 highlight）那座是金砖，主角站在它旁边；数值是点阵字，标签写在地面上。竖屏：RPG 状态栏里的分段血条 |
| steps | 海上世界地图。每步一座岛，没到的上锁；虚线路一段段画出，主角沿路走到当前岛。横屏岛一排、字在岛下；竖屏岛之字排、字在右 |
| compare | 1P 对 2P 选人画面。左蓝右红（竖屏上蓝下红），两张卡片中间是 VS 和对峙的两个主角；右边是推荐方：金框、主角带装备。没入场的一方是虚线空位 + 黑影「?」 |
| quote | 地下关 NPC 对话：头像框里是红色 NPC，by 是名字牌，引语逐字打出，打完 ▼ 闪 |
| end | 夜里的通关画面：旗子升顶、城堡、烟花，STAGE CLEAR 下是像素大字、副标题和金色按钮（▶ 光标） |

## 来自原画法库（风格库的 G-街机关卡）

`lib/px.mjs`：像素视图、5×7 点阵字库（加了 $ &）、阈值化中文像素大字、RPG 双线面板、贴图缓存。`lib/sprites.mjs`：小机器人（四个姿势、受击眼）、六件装备、12×12 图标、金币、问号块、地面砖、旗子、星光。`lib/world.mjs`：抖动渐变天空、云、山、灌木、视差星空、光点、城堡剪影、HUD、闪白、碎屑、烟花、金币雨、带装备的机器人。改动：字体换成 `E.font`；格子大小按画幅算；新加 `lib/text.mjs`（E.fit 排好的字按字号选像素字或高清字，点阵字和中文单位混排）。

## 和原样片比少了什么

- 没有像素马赛克转场（引擎只有 cut / fade / slide，没有每场的转场钩子），用 cut。
- 没有按旁白逐词触发的事件：推近、整屏抖动、闪红、问号块 OK / MISS、掉心。动画只按 s.p(i) 和 s.t。
- 没有芯片音色配乐和金币 / 顶块音效：选了 drive + marimba + 鼓，C–G–Am–F，140 拍；音效 pop / whoosh / chime。
- 字幕不再给关键词上金币黄（没有关键词表）；装备只是装饰，不再对应原来的六个概念。

## 已知的毛病

- HUD 的分数、金币按入场元素数涨（场序 ×1000 + 已入场 ×100），是游戏外壳，不是内容；跨场不累计真实数。
- 关卡背景画在版式里（bg 拿不到这一场的版式），所以只适合 cut 转场。
- 竖屏 compare 两边各 4 条时，条目字约 38px，偏小。
- 横屏 bars：金砖塔旁边的主角，可能被一根很矮的相邻柱子的数值压到。
- steps 主角在两座岛之间走的那几帧会压住岛上的序号。
- 中文像素字 15–18 格高时，笔画多的字（戴、播）发块，1080p 能读，缩略图上糊。
- 1:1 画幅没出图验证（HUD 改两行，版式走横屏分支）。
- 改了两轮仍不行就换画法的：compare 原来把主角放在卡片里一栏，卡片字太窄；改成主角放到中间对峙。
- 压力测试的 video.json 在 `dev/ports/out/arcade/stress/`。
