# arcade 街机关卡 · 风格包说明

来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

8-bit 像素游戏风。`"theme": "arcade"` 即用。所有图形落在像素网格上（短边 1080 时一格 6px），贴图最近邻放大，没有圆滑边。每种版式是一个游戏画面，字幕是 RPG 对话框，最上层是扫描线和 HUD（1P、三颗心、SCORE、金币、STAGE 01 这样的关卡号）。场和场之间是像素马赛克转场。

## 九种版式

| 版式 | 画法 |
|---|---|
| title | 白天外景卷轴：青绿天、长条云、远处淡紫的平顶台地、圆冠树，草皮下是紫色菱格土。玫红切角招牌（两头各一颗星）上是中文像素大标题，kicker 是压在招牌上沿的小牌，下面副标题和闪烁的 PUSH START；主角在地上跑、吃迎面来的金币 |
| statement | 黄昏城市：两层楼群剪影，窗户有亮有暗，天线红灯闪。RPG 消息框里逐字打出中文像素字，高亮词金币黄；主角站在框下（横屏左下、竖屏正下），头上冒「!」 |
| bullets | 星空装备栏。每条要点是一格装备：没入场是虚线空格，入场时图标落进格子，同一件装备落到主角身上；主角站在喷火的悬浮台上；▶ 光标停在最新一条 |
| number | 奖励关。同心方环调色板循环；记分牌里点阵数字从 0 跳到目标值；跳完后两侧金币雨、烟花 |
| bars | 横屏：一排圆角方块塔一层层长高，最高（或 highlight）那座是金块，主角站在旁边；标签写在地面上。竖屏：RPG 状态栏里的分段血条 |
| steps | 海上世界地图。每步一座岛，没到的上锁；虚线路一段段画出，主角沿路走到当前岛 |
| compare | 1P 对 2P 选人画面。左蓝右红（竖屏上蓝下红），中间是 VS 和对峙的两个主角；右边是推荐方：金框、主角带装备 |
| quote | 地下关 NPC 对话：墙和天花板是圆角石块，头像框里是玫红 NPC，by 是名字牌，引语逐字打出 |
| end | 夜里的通关画面：领奖台从地里升起，三个机器人依次落到台上（冠军在中间、全身装备、隔一会儿跳），旁边台座上奖杯闪光；烟花、彩纸；STAGE CLEAR 下是大字、副标题和金色按钮。横屏领奖台在左下、奖杯在右下，竖屏两样并排在文字下面 |

## 声音

配乐 drive + marimba + 鼓，C–G–Am–F，140 拍；引擎给入场配 pop、场间 whoosh、number 和 statement 配 chime。`sounds(TL)` 另加游戏音效，一场不超过三个，时刻按入场进度算、和画面对齐：title 吃前三枚金币（tick），statement 和 quote 开始打字（type），bullets 前两件装备落位（click）和装齐（chime），number 分数跳完（chime）和金币雨（tick），bars 金块塔长满（chime），steps 走到第二、三座岛（tick）和最后一座（chime），compare 的 VS（thud + glitch），end 奖杯落定（chime）和头两朵烟花（thud）。

## 2026-11 修订：和一款经典横版过关游戏拉开距离

- 去掉：结尾的旗杆和砖砌城堡、黄昏关的城堡剪影、问号块贴图（原来在 lib 里没用上）、天蓝天 + 绿色阶梯山 + 灌木 + 橙红砖地这一套、招牌的四颗铆钉、「1-1」式关卡号。
- 换成：上表里的外景、黄昏城市、圆角方块、悬浮台、领奖台和奖杯。主题色 bg 改青绿 #2aa6a8、accent2 改玫红 #e8386c，夜景、海面、对比、地下关跟着换色。
- 加了：像素马赛克转场（`transition` 函数，0.5 秒：上一场的格子 2→4→8→16 倍放大，过半换成这一场再缩回）；上面那组音效。
- 保留：小机器人、HUD、对话框、像素字、金币、装备，各版式的摆法不动。检查输出在 `dev/ports/out/arcade2/`。

## 已知的毛病

- 画法库来自风格库的 G-街机关卡（`lib/` 下：px 像素视图和字、sprites 贴图、world 布景和 HUD、text 排字）。没有原样片里按旁白逐词触发的事件（推近、抖屏、掉心）和芯片音色配乐。

- 转场时字幕和 HUD 不打马赛克，字幕在转场一开始就换成新一场的（引擎先画转场，再画字幕和最上层）。
- 横屏片尾领奖台用 1 倍机器人（避免压到两行长副标题），比竖屏的小。
- HUD 的分数、金币按入场元素数涨，是游戏外壳，跨场不累计真实数。
- 竖屏 compare 两边各 4 条时条目字约 38px，偏小；横屏 bars 金块塔旁的主角可能被很矮的相邻柱子的数值压到；steps 主角走在两岛之间时会压住序号。
- 中文像素字 15–18 格高时笔画多的字发块；1:1 画幅没出图验证。压力测试的 video.json 在 `dev/ports/out/arcade/stress/`。
