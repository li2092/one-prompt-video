# isometric 等轴测机房 · 风格包说明
来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

冷浅灰底上的 2.5D 机房，`"theme": "isometric"` 即用。送料机、传送带、盖章检查站、门架、机柜、柱体和货箱都按等轴测投影画，零件落位时加速下落、触地压扁回弹、扬尘、镜头轻震；每场机位水平来回转 2～3 度。字全部在屏幕空间：白底圆角牌加引线，钉在机器上。字幕是白色圆角底板，最上层是左上角的 LINE 铭牌和场次小方块，转场沿 1:2 斜线百叶擦除。配乐 108 拍，Dm9–Bbmaj7–Fadd9–Csus4，电钢琴加轻鼓；门架、牌子、生产线落地时加一声 thud。

## 九种版式

| 版式 | 画法 |
|---|---|
| title | 一整条生产线（送料机、传送带、盖章站、记录仪、工具架、货箱）一件件落位；标题从上方落下压扁回弹，kicker 是强调色牌 |
| statement | 整句写在一块带厚度的白牌上，吊索放下、两条腿着地扬尘，吊索收走；高亮词垫一块强调色键帽；腿边摆货箱和记录仪 |
| bullets | 一座机柜，每条是一层抽屉，依次推进去、指示灯亮；右边一列牌子用引线钉在各自那层，最新一条强调色 |
| number | 一台大屏机柜，数字在屏上滚到目标值（字贴在立面上，跟着透视斜）；label、note 是挂在屏幕下沿的牌子 |
| bars | 横屏：一排方柱立在各自的地砖上按数值升起，数值牌浮在柱顶。竖屏：一根立柱挑出几根横梁，按数值往右伸，标签在左列 |
| steps | 传送带上几座门架依次落位，号牌亮起，一只货箱走到最新一站。横屏牌子在门架上方一字排开；竖屏机位对着带子正面，牌子在右边 |
| compare | 两条生产线：左边普通的（灰方块、门架不亮），右边装了盖章站和记录仪（强调色方块盖章带勾）；条目前是小立方体 |
| quote | 一台记录仪，屏上日志滚动，引线拉到白色大牌；引语逐行打出，左上角强调色键帽是引号，出处是深色牌 |
| end | 生产线整机运转，四周围栏一节节升起；标题落下，按钮是一枚定时被按下去的强调色键帽 |

## 和原样片比少了什么

- 没有原样片的题材和寓意：中心芯片、外圈六个模块、对话记录堆、三层楼、吊走零件、光标点链接都没搬。芯片画法删了。
- 没有按旁白逐词触发的镜头推拉、环绕关键帧和标签划掉；动画只按 s.p(i)、s.cue(i)、s.t。
- 方块不再分对错：原来红块被推下传送带，这里只有「盖章带勾」一种结果，避免替内容下判断。
- 配乐用引擎现成的合成器，没有原来的分段编排（抽空一小节、逐层加乐器）。转场的 whoosh 由引擎按 cut 音效放，比原来早 0.25 秒左右。

## 已知的毛病

- statement 的白牌和腿是屏幕空间画的，正对镜头，不是真的等轴测；机位只转 2 度，看不出破绽。
- 数字贴在大屏立面上会跟着透视斜约 20 度；很长的数值在竖屏屏幕上字会变小。
- 横屏 steps 五站时，牌子宽度受站距限制，常折成两行。竖屏 steps 机位转到 83 度，接近正面，等轴测感弱一些。
- bullets 条目多、抽屉矮于约 100 像素时，牌子改为在整个高度均匀排开，引线变斜。
- 记录灯红色、明暗、投影是固定色，不跟 colors 走；深色 colors 测过能看，1:1 画幅没出图验证。
- 改两轮不行换了画法的：竖屏 bars 先是和横屏一样的方柱，再改成横梁加梁上标签（标签被斜梁压住），最后把标签挪到立柱左边一列。竖屏 steps 号牌原来朝 +y 被看成一条细边，改成朝 +x。
- 压力测试的 video.json 在 `dev/ports/out/isometric/stress/`，深色换色测试在 `dev/ports/out/isometric/colors/`。
