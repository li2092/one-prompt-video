# detective：调查线索板风格包
来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

全片是一整块软木板，一场是板上的一块区域。卡片、拍立得、便签、撕下的纸条用图钉钉上去（先放大带投影，落定时图钉弹一下），红线把它们连起来，红色记号笔圈出重点。右上角一枚红钉，红线从它连到上一场和下一场的同一枚钉子，场尾拉出去；换场时镜头顺着这根线在板上平移（右、右、下、左、左、下的蛇形），中间拉远约 13% 再推近。软木是一张能四方平铺的贴图，按每场在板上的位置铺，所以两场在接缝处接得上，拉远时露出来的板面也按位置补画。镜头一直有几像素的手持漂移，数字圈好、片尾按钮钉上时轻震一下。左上角黑底标签「线索」后面一排图钉表示场次。字幕是证物标签（剪角、扣眼、麻绳、细红框），衬线字逐字略错位。台灯暗角压在画面上、字幕下面。

颜色全部从 `this.c` 推：`bg` 软木，`card` 卡纸，`fg` 墨色，`accent` 红线、红钉、记号笔，`accent2` 便签黄，`line` 卡上的蓝横线，`muted` 铅笔灰；粉色、浅蓝便签、牛皮纸、坐标纸由它们混出来。字体：标题、卡头、字幕用 serif，手写用 hand，毡面字板用 sans。

## 九种版式
- `title`：档案卡钉在正中，衬线大标题、卡头红线，副标题手写在横格上；kicker 是一张撕下的白纸条，红笔写，胶带贴在卡角；卡后先钉两张拍立得，红线从卡片的钉子拉过去。竖屏拍立得挂在卡片上下。
- `statement`：大索引卡，句子按卡上横格排，高亮那段红字、红笔圈；卡角钉一张写着叹号的便签。
- `bullets`：每条一张便签（黄、粉、浅蓝轮换），红线依次连起来。横屏一排，挤时改两排；竖屏一列，钉子钉在左边，红线顺左边串下来。
- `number`：数字手写在大索引卡上，从 0 滚到目标值，滚完红笔圈起来；label 写在横格上，note 是钉在卡角的便签。
- `bars`：钉在板上的坐标纸，柱子是手画的排线方块，数值手写在顶上；高亮那根用红笔画、数值圈起来。竖屏改横条。
- `steps`：几张拍立得（相片里只画图标剪影和色块），红线依次连过去，步骤写在相片下面的白边上，角上圆贴纸写第几步。横屏一排，窄画幅两排；竖屏左右交错往下排。
- `compare`：左右两组物证各是一个档案夹，标签写组名（右边红标签），夹里一张索引卡逐条手写，左边铅笔短横、右边红勾，中间红笔不等号。竖屏上下排。
- `quote`：撕下来的纸条，两角胶带，字逐个写出来，左上角红色大引号；出处写在钉在右下角的便签上。
- `end`：标题插在毡面字板上（白色塑料字逐颗略歪），四周空处钉几张小拍立得和问号、叹号便签，红线依次全部拉到字板的钉子上；副标题手写在纸条上，cta 是便签，钉好后红笔圈起来。

## 和原样片比少了什么
1. 原样片是真的一块板（世界坐标），七场物件同时存在，片尾拉到全景看所有线索连向中间。这里每场各画各的，板的连续感只靠按位置铺的软木、场间红线和平移转场；没有全景。
2. 没有按旁白逐词触发的圈注、打勾打叉、勾叉来回跳；镜头没有每段推近抬头卡再拉开、慢推和 0.1 秒推近，只有手持漂移和两处轻震（慢推会让转场两场的软木对不上缝）。
3. 相片内容只剩图标和色块；剪报、证物袋、报告纸、嫌疑人照、案卷号牌（改成了片尾的毡面字板）没有搬。
4. 原样片的毛笔体红字改成手写体加粗描边；字幕的逐字浓淡去掉了，只留错位。

## 已知的毛病
- 本机没有手写字体，总览图里的「手写」都是黑体加逐字歪斜，看着更像打印的字。有手写字体的机器上字形会变，版面按实际字宽排，不会出框。
- 软木颗粒随手持漂移每帧都在动，编码器省不下来：44 秒横屏成片 29.5 MB，比平面风格大。
- 两排便签、两排拍立得之间那根换行的红线从纸底下穿过，只在缝里露一点。
- 竖屏 number、statement 没有 note 时，下面三分之一是空软木。
- 下一场第一个元素在 0.35 秒入场，落在 0.75 秒的平移里，镜头还在走它就钉上了。
- 片尾四角的小物件在中间那组太宽或太高时（1:1、标题很长）会少放或不放。
- compare 中间的不等号是装饰，两边内容相近时语义不太对。
