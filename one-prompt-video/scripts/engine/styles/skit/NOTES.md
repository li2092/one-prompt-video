# skit 办公室小剧场 · 风格包说明
来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

`"theme": "skit"` 即用。扁平插画的办公室：米黄墙带细竖纹、踢脚线、木地板，木色桌椅。两个普通的办公室角色来演内容：a 年轻、乱发、上衣用 `accent`（全片唯一的饱和色），b 年长、灰发、眼镜、开衫用 `accent2`。人物站着约 6.5 个头高，占画面高度三分之一左右；横屏站在内容两侧，竖屏站在下面、内容在上面。新的一条内容出现时人物有反应：点头、举手、冒汗、转头、蹦一下、头顶冒感叹号或三道闪光、边说边比划。整场镜头以地面为轴慢推 2.5%；转场是 0.42 秒的快速横推；字幕是奶油色圆角底板、整圈细边；最上层是只算一次的纸纹颗粒和暖色暗角。

## 九种版式

| 版式 | 画法 |
|---|---|
| title | a 双手把一块白卡举过头顶，标题落一道马克笔线，副标题在下面；kicker 是拍在牌子左上角的强调色便签。b 一愣后拍手。横屏左边摆着工位，竖屏换成绿植 |
| statement | 墙上从上往下展开一张海报（宽度跟字走），高亮词先刷马克笔再被圈出来；b 指着那个词边说边比划，a 抬头、冒感叹号、点头 |
| bullets | 白板（高度跟内容走），标题用马克笔写；每一条是 b 甩到白板上的一张便签，排成格子；a 每来一张点头，最后一张举手 |
| number | 数字像刷在墙上的大字（强调色加错开的深色），从 0 滚上去；label 是钉着的纸牌，note 是便签。a 往后仰，滚完蹦一下、冒感叹号、冒汗；b 摊手介绍 |
| bars | 横屏：长桌上一摞摞文件夹，一层层落下，数值在摞顶小卡上，标签贴在桌子挡板上，强调那摞是强调色；竖屏：墙上文件柜，每格一排活页夹。a 看到强调那摞吓一跳 |
| steps | 横屏：晾绳上用木夹子夹卡片，a 一张张递过去，卡片晃两下，之间画手绘箭头；竖屏或横屏一排放不下（如 1:1）时卡片钉成一列。b 每张点头，最后拍手 |
| compare | 两人各举一块牌子：横屏站两边握着牌子边沿，竖屏站在牌子下举过头顶；右边强调色牌头、条目逐个打勾，右边举起时 a 蹦一下，b 扭头冒汗 |
| quote | a 说出一只大对话气泡（横屏在头的右上方，竖屏在头顶），大引号是强调色，字边说边出来；b 听着点头 |
| end | 两人举着杆子，横幅从中间往两边展开；cta 是两人中间的强调色按钮，出来后 a 蹦一下、两人挥手 |

## 来自原画法库

`lib/person.mjs`：人物（两段 IK 手臂、表情、眨眼呼吸、冒汗、转头），删掉了原片的发型变体，汗滴放大 1.5 倍；颜色改成跟 `accent` / `accent2`。`lib/props.mjs`：桌、椅、笔记本、勾、手绘圈和箭头照搬；白板、便签、长桌、文件夹、活页夹、木夹子、气泡、盆栽是新画的。`lib/stage.mjs`：墙地、转头过渡照搬；点头、蹦、说话、拍手、挥手、头顶符号是新写的。投影全部换成错开的半透明暖灰，不用 shadowBlur。

## 和原样片比少了什么

- 原片的道具和对应关系（答卷、提示词卡、门禁卡、审核章、停止铃、虚线框、头上贴标签）全部去掉；人物不代表任何概念。
- 没有按念词触发的动作和每场单独设计的镜头推拉横摇，只有慢推。a 不再坐在工位上打字，工位只在 title 和竖屏 statement 里当布景。
- 字幕不在逗号处按逐字时间戳拆条，用引擎的分段。配乐只能选现成参数：bright + pluck + 鼓、116 拍，没有原片的马林巴切分和分场编配，没听过。

## 已知的毛病

- 本机没有手写体，便签、气泡、标签走 `hand` 时退回黑体。
- 竖屏人物占下面三分之一，内容区只有约 730 像素高：五条要点的便签字约 50 像素，六根柱子的文件柜每格很矮，标签字约 30 像素。
- 1:1 用横屏摆法：compare 两块牌子偏窄，条目常折成两行。
- 抛便签、递卡片时，两条内容的入场间隔短于 0.45 秒，手臂会少一段收回、看起来一顿。
- 值为 0 的柱子没有文件夹，数值卡直接放在桌面上。
- 转头是头部水平镜像，过渡中有一两帧头偏窄；手臂是两段 IK，举牌、指点偏硬；没有走路。
- 完整出片（44.6 秒 1080p）本机约 15 秒，文件 18.8 MB。
