# chrome 酸性镀铬 · 风格包说明
来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

Y2K 酸性风。`"theme": "chrome"` 即用。底是流动的液态渐变（1/8 大小的离屏画布逐像素算正弦场、查色阶、平滑放大），三套色阶按场轮换，上面一层慢慢扭动的白色细网格（每场第一个元素落地时在中心鼓起一下）、四角镀铬液滴、背景闪星、暗角。内容多的版式（bullets、bars、steps、compare、quote）底压暗一半、网格变淡、闪星减少。主角是镀铬立体字：深色光晕、粉到紫的挤出、深色描边、分段金属渐变（一道窄的暗地平线）、上沿亮边、斜向反光，银、荧光绿、粉三种；做成贴图只算一次，分「底层」「字面」两遍画，相邻的字不互相压暗。中文且字号不大于 120 时换成地平线只压到中灰的色阶，笔画多的字不糊。字幕是深紫胶囊加镀铬边框，英文和数字荧光绿，两端各一颗星；最上层左上 `LIQUID CHROME`、右上场次；转场 0.48 秒，旧画面横向液化，新画面被一道波浪液面从下往上推上来，液面边缘一道镀铬亮线和几颗星。

## 九种版式

| 版式 | 画法 |
|---|---|
| title | 镀铬大字横向拉长后弹回，爆一圈星；外面一圈荧光绿液态光圈画出来；kicker 是斜贴的白边贴纸，副标题是深色胶囊 |
| statement | 整句镀铬大字逐行液化后凝固；高亮词是荧光绿镀铬，下面流出一道波浪线、爆一圈星 |
| bullets | 每条是一枚镀铬边深色胶囊，宽度跟着字走，奇偶行错开；前面一枚圆贴纸写序号；横屏右边空着时放一张慢慢转的彩虹光盘 |
| number | 荧光绿镀铬数字从 0 滚上去（逐字贴图拼），单位是粉色镀铬，一圈粉色光圈；落地一震；说明和小字是深色胶囊 |
| bars | 镀铬柱子，最高的或 highlight 是荧光绿，数值也是镀铬字；横屏竖着长、标签是柱下胶囊；竖屏横着长；方屏柱子多时横着长、标签放左边一栏 |
| steps | 一串镀铬胶囊，荧光绿箭头连起来，每枚顶上一枚圆贴纸序号，最后一步是荧光绿贴纸；横屏一排，竖屏和方屏往下排 |
| compare | 粉、绿两块白边贴纸面板从两边滑进来撞上，一震、中缝爆星、弹出镀铬 VS；面板标题是镀铬字，条目深色字；竖屏上下撞 |
| quote | 镀铬边框的深色面板落下来、略斜，字逐行浮出；左上角粉色镀铬大引号；出处是右下角斜贴的荧光绿贴纸，没有出处时换成绿色后引号 |
| end | 镀铬大字外面一圈星沿椭圆转、各自闪；副标题是深色胶囊；按钮是荧光绿贴纸，一个光标滑过来点一下 |

## 来自原画法库（风格库的 Z-酸性镀铬）

`lib/acid.mjs`：镀铬字贴图、液化绘制、入场动作（pop、stretch、tall、drop、spin、melt、滑入）、四角星、爆星、闪星、贴纸、胶囊标签、镀铬面板、柱子、光圈、彩虹光盘、液滴、箭头、超宽字距点缀、光标。`lib/liquid.mjs`：液态底、扭曲网格、液滴和闪星、暗角。转场和字幕照原 `style.mjs` 改写。改动：颜色从八个颜色算（紫色由 bg 调亮得到，挤出和色阶都跟着换色）；字体按类别取；尺寸乘 E.u；星和光圈的发光改成预先画好的贴图和半透明描边，`shadowBlur` 只在一次性的贴图里用。

## 和原样片比少了什么

- 没有按旁白逐词触发的动作：关键词处网格鼓起、「时对时错」一直液化晃、贴纸翻面、满分液化流走、芯片和光圈、答案卡填进去。这里每个元素只在入场时动一次，之后待机微晃和扫光。
- 原题材的图标（眼睛、扳手、停止牌、盾牌、文档、地球、对话等）和芯片没有搬，只留了光标；贴纸字体原来是一款手写感黑体，换成 sans 900。
- 字幕高亮只按「英文和数字」，不按关键词；长句不按念到的字拆成两条，用引擎按标点切段。
- 配乐用现成参数（drive、Bm–G–D–A、pluck、带鼓、128 拍），没有原来的超级锯齿、808 和 FM 铃音。音效 pop / whoosh / chime，另在 title、statement、compare 撞上、end 各加一个。

## 已知的毛病

- 出帧较慢：1080p 约 39 毫秒一帧（液态底每帧算一遍），44 秒的片完整出片 66 秒；液态底细节多，44 秒成片 33 MB。
- 滚动的数字和柱顶数值是逐字贴图拼的，没有扫光。
- 荧光绿镀铬字落在荧光绿色带上时对比偏低，靠深色描边和光晕撑着。
- `#7df9ff` 青色（闪星、光盘）不在八个颜色里，换色时不变；`card` 不换时胶囊仍是紫色。bg 换成浅色时紫色会被调成接近白，液态底发白，没有处理。
- 方屏 compare 两块面板偏窄，条目常折成两行；方屏 title 的光圈会压过 kicker 贴纸的一角。
- 竖屏 title、number、quote 的内容在内容区里居中，整体偏上半屏，下面留白较多。
- lib 里取色用了 `E.theme.c`（style-packs.md 没写这个字段，引擎里有）。测试用的方屏、压力、换色 video.json 在 `dev/ports/out/chrome/`。
