# collage：剪贴拼贴风格包
来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

一场是一页杂志拼贴：牛皮纸底上压一张按场换色的淡色杂志页（分栏正文行、一角粗网点、角上一个只露一部分的错版装饰词），两张粗网点色页从对角露出来，边上贴旧报纸、方格纸、横线本和胶带。底每场只算一次。内容全是贴上去的纸片：撕边露白芯、带投影，入场是"拍上去"（从 1.2 倍落下、转正、落地一抖），落定后每秒 8 格轻微抖动。主色走 `this.c`：底 bg 是牛皮纸，accent 是荧光粉跳色，accent2 墨绿，line 是红笔，card 是米白纸；芥末黄、灰蓝、浅粉、荧光黄绿等旧纸色是固定的。

## 九种版式

- `title`：网点图片块垫底，标题是剪字（一个字一块底、不同字体、各自略歪），逐字拍上，必要时折成两行；kicker 是别着回形针的黑纸条，副标题是报纸条，角上一张粉色爆炸星贴纸。
- `statement`：一句话按词剪成纸条，一张张拍在横线本纸上；高亮那段是强调色纸条，贴完红笔圈出来（折到两行就圈两处）。
- `bullets`：一条一张旧纸条，左端编号小纸块，右端一截胶带；横屏右边有空时贴一张网点图片块。
- `number`：每一位数字一块剪字，拍在网点图片块上；单位是黑纸条；贴完红笔圈起来。label 是报纸条，note 是蓝笔逐字手写。
- `bars`：报纸条当柱子，从一条白纸条后面抽上来，顶上压胶带，数值是小纸签；高亮那根是强调色网点纸，数值签被红笔圈住。竖屏改成横条，从左边一条竖纸后面抽出来。
- `steps`：纸卡错落贴成一串，相邻两张用胶带连起来，缝里红笔画箭头；竖屏一列，胶带在右侧。
- `compare`：两张不同颜色的撕纸从两边滑进来，标题是剪字；左边条目前是墨笔短横，右边（强调色网点纸）打红笔勾；中间拍一张 VS 爆炸星。竖屏上下摆。
- `quote`：一张订书钉钉住的黄便签，字逐字手写出来；左上角一块剪下来的黑底大引号；出处是一条贴胶带的白纸条。
- `end`：标题剪字贴在一条黑纸上，副标题红笔手写，cta 是一张剪下来的优惠券（虚线框加剪刀记号）。
- 字幕：每行一条撕下来的白报纸条，相邻两行歪向不同方向。转场：新一页从左往右盖上来，前沿是锯齿撕边加白芯加投影，0.3 秒。最上层：原风格没有，不写 `overlay`。
- 配乐：bright，D-Bm-G-A，marimba，有鼓，118 拍/分。音效：入场 pop，换场 whoosh，number 和 statement 的第一个元素入场时 thud；另加片头标题贴完 thud、数字被圈时 type、VS 贴纸 pop、优惠券 chime。

## 来自原画法库的部分

`lib/clip.mjs`：撕纸轮廓和纸片、纸面颗粒、四种纸纹、胶带、半调网点、错版印刷字、爆炸星、回形针、入场和定格抖动、剪字、手写、手画线和圈和箭头和勾、整屏抖动。`lib/page.mjs`：每场的杂志页底、撕纸条字幕、撕边转场。新写的：订书钉、剪刀记号、网点图片块、按词剪开的纸条字（statement）、九种版式的构图。

## 和原样片比少了什么

1. 原样片的剪字、批注、贴纸都挂在旁白念到的那个词上；这里只按元素的入场时刻，一个元素内部按固定间隔逐字拍上。
2. 原样片有剪纸机器人、芯片、文档、图标、橡皮章、揭起退场；这些和题材绑定，没有搬。场内元素只进不出。
3. 原样片的剪字用了得意黑和毛笔楷书，手写用霞鹜文楷。这里只用引擎的四类字体；本机没有手写体，`hand` 退回黑体，手写靠逐字的轻微歪斜和错落来读出。
4. 原样片的配乐是拍手加跳动贝斯加钢片琴动机，这里只能选现成参数。

## 已知的毛病

- bullets 横屏右边的网点图片块是纯装饰，像一张空卡片；条目长时它会自动不出现。
- 剪字按"比正常字宽 1.38 倍"估宽度给 `E.fit`，英文字母的字块更宽，画时会再整体缩一点，这部分缩小不会记进报告。
- statement 的纸条字按词切，词太碎时一行纸条很多；两个单字会并成一张。
- 杂志页角上的大号装饰词（ISSUE、NOTE、DATA……）按版式取，透明度 9%；竖屏时它紧挨在字幕条上方。
- 只验证过默认配色；把 `bg` 换成深色、或把 `card` 换成深色没测过。1:1 画幅没出过图。
