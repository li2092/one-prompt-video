# cosmos 宇宙星图 · 风格包说明
来源：移植自一套由JiMiL 指挥 Claude Opus 5.5 设计的风格库。

深空风。`"theme": "cosmos"` 即用。底是深空斜向渐变、一条弯曲的星云带和三层按深度视差的星点（星云、星点只算一次），每场开头背景从略推近、略转的位置回正，之后慢漂。金色（accent）只给恒星和强调，青色（accent2）给轨道、卫星和标注线。字逐字淡入、略上浮，垫一层深色柔影，标题加同色柔光。字幕是无底框白字，上方一小段三星连线；最上层是左上 `STAR MAP`、右上场次和一条虚线轨道进度线。转场 0.7 秒：上一场推进放大淡出（字先在 0.15 秒内淡掉），新场从中心以光圈展开，光圈边一道青环，星光拉成放射线。

## 九种版式

| 版式 | 画法 |
|---|---|
| title | 一颗恒星，三道倾斜的轨道环从它后面绕到前面，背后星图网格；片名在右（竖屏在下），引线把星和片名连起来 |
| statement | 句子居中，上下各一组星座先后连出来，一颗彗星划过；高亮词金色发光 |
| bullets | 恒星（横屏在左侧可见，竖屏在画面外只露暖光）的一道轨道弧上，行星一颗颗点亮，受光面朝恒星；最新那颗套一圈小轨道 |
| number | 日食：月面滑过来挡住太阳，日冕和冕流亮起，接触时闪一颗钻石环；数字写在月面上滚上去，外圈星图刻度；说明横屏在右、有引线，竖屏在下 |
| bars | 横屏从地平线升起的光柱，柱顶一颗星，最高（或 highlight）那根是带芒的金星；竖屏横向光柱 |
| steps | 一条虚线航迹一段段画出，彗星头在线尖上，到站时行星点亮，终点是金色；横屏一排字在站下，竖屏蛇形往下字在右 |
| compare | 双星：一冷一暖两颗星在同一条扁轨道两端，质心一个十字；右边（推荐）是金色，条目前是四芒小星 |
| quote | 一颗带环的气态行星升起，光从引语那边照过来，一颗卫星绕它；引语左对齐，出处像星图注记 |
| end | 旋涡星系在上半幅慢慢转，偶尔一颗流星；收束句在下，按钮的字被一圈小轨道围着，一颗卫星绕它走 |

## 来自原画法库（风格库的 Y-宇宙星图）

`lib/space.mjs`：柔光贴图、星点数据、星云贴图、暗角和字幕带压暗、背景合成（原 `space()`）。`lib/bodies.mjs`：恒星、卫星、轨道椭圆、星图网格、冲击环、彗星、引线、环形骨架、星系贴图（原样搬，改为从主题取色、尺寸乘 E.u、缓存走 E.once）；新写了带明暗和环的行星、日冕、星座、四芒小星。`lib/text.mjs`：逐字显现的字（原 `label()` 的做法，改为画 E.fit 排好的多行字）、场标题。转场、字幕、外框照原 `style.mjs` 改写。

## 和原样片比少了什么

- 没有按旁白逐词登记的镜头（推近、拉远旋转、逐个飞到星系前）。现在只有背景随每场开头回正和慢漂，画面内容不跟镜头动。也没有按词触发的事件：勾叉落在轨道上、轨道抖动变红、彗星射入、假星座、光芒胀成六倍、系绳断开。动画只按 s.p(i)、s.cue(i)、s.t 走。
- 字幕不给关键词上色，长句不按念到的字换条，用引擎的按标点切段。
- 配乐用现成参数：ambient、Dm9–Fmaj9–Cadd9–G、epiano、无鼓、88 拍；没有原谱里每个动作一个钟音和全片渐强。音效 tick / whoosh / chime，另在片头、片尾加 swell，steps 最后一站加 chime。
- 原外框的书名换成装饰词 `STAR MAP`；原题材用的线条图标（文档、时钟、地球、链接、气泡）和勾叉没有搬。

## 已知的毛病

- number 场开头约 0.9 秒里太阳露出一半亮的月牙，再被月面盖满；原来露出一整个亮盘、切进来有一下强光，改了一轮后变成月牙，亮度仍偏高。
- number 的值很长（如 `1,280`）时数字缩小放进月面，不报「字偏多」（用了 quiet）。
- 紫色 `#a98bff` 不在八个颜色里：间隔的行星、quote 的行星、星云的一部分用它，换 colors 时这些不变；星云只有青色那几团跟着 accent2 变。
- bars 金色那颗星的芒会穿过它头上的数值（芒很淡，字有深色柔影）。
- 横屏 bullets 条目短时右边四成是空的；竖屏 title 的字块偏上，下面留白较多。
- statement 的星座只有两种固定形状；句子占满画面时，星座被挤到一条约 100px 的带里，可能伸到内容区外。
- 没出过 1:1 画幅；steps 只测过 5 站。lib 里取色用了 `E.theme.c`（style-packs.md 没写这个字段，引擎里有）。
- 出片约 58 毫秒一帧（1080p，45 秒片 78 秒出完）。压力测试的 video.json 在 `dev/ports/out/cosmos/stress/`。
